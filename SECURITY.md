# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and to the latest
published 0.1 Public Alpha when applicable. Older development artifacts are not
supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include
exploit details, private paths, credentials, game files or third-party mod
content in a public discussion.

Use GitHub's private vulnerability reporting through the repository's
**Security** tab:

<https://github.com/CeberusOne/Tpf2-Mod-Studio/security/advisories/new>

Private vulnerability reporting must be enabled before
`v0.1.0-alpha.1` is published. If the private form is unavailable, contact the
repository owner through their GitHub profile to request a private reporting
channel without disclosing technical details publicly.

Include, when available:

- affected version and package type;
- operating system;
- impact and prerequisites;
- minimal reproduction steps;
- suggested mitigation;
- whether the report may be credited publicly.

The project will acknowledge a private report, investigate it, coordinate a fix
and publish an advisory when disclosure is safe. No response deadline is
promised during the volunteer Public Alpha phase.
